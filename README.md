# zrt-landing — рекламные страницы adv.zrt-school.ru

Статический сайт школы мотокросса ZRT: обычные HTML/CSS/JS, без сборки и
зависимостей. Всё содержимое каталога `site/` публикуется на
**https://adv.zrt-school.ru** автоматически при merge в `main`.

```
site/            ← ровно то, что видит клиент (index.html, стили, скрипт, 404, robots)
templates/       ← болванка новой страницы
scripts/         ← проверка страниц перед публикацией
docs/DEPLOY.md   ← как устроен выкат, откат, TLS, ротация ключа
AGENTS.md        ← правила для агента, который правит контент
HANDOVER.md      ← инструкция для маркетолога
```

## Быстрый старт

```bash
node scripts/check-site.mjs     # проверка страниц (её же гоняет CI)
open site/index.html            # посмотреть страницу локально
```

Сборки нет: файл из `site/` открывается в браузере как есть.

## Как публикуется

| Действие | Что происходит |
|---|---|
| Открыт pull request | проверка страниц + черновик на `/_preview/pr-<номер>/`, ссылка комментарием в PR |
| Merge в `main` | проверка страниц + публикация на боевой адрес (меньше минуты) |
| Откат | `git revert` → pull request → merge |

Выкладывает только GitHub Actions: ключ выката существует в секретах репозитория
и на сервере прибит к одной команде. С ноутбука опубликовать нельзя — намеренно.
Детали и диагностика — [`docs/DEPLOY.md`](docs/DEPLOY.md).

## Известные ограничения

- **Форма заявки не отправляет данные** (`site/script-improved.js`, `handleSubmit`):
  показывает «успешно отправлено» и всё. Рекламный трафик на такую форму = потерянные
  заявки. Нужен приёмник (amoCRM/почта/телеграм) — отдельная задача.
- Фото главной страницы грузятся с внешнего `static.tildacdn.com`.
