# Cloudflare Worker приёма лидов ZRT

Исходник соответствует опубликованному Worker `zrt-amocrm-lead-receiver` и
хранится в репозитории, чтобы изменения интеграции с amoCRM проходили проверку
и code review до публикации.

Базовый исходник сверен 08.08.2026 с активной версией Cloudflare
`8bae4047-00d0-42db-b498-2f03b4e99698`; секреты при сверке не выгружались.

Каждая новая сделка получает существующие теги `adv.zrt-school.ru` и
`Форма: Новичок`/`Форма: Уже катал`, а также обязательные теги
`1000оффер` и `Директ_РСЯ_Лендинги`.

Проверки без отправки тестового лида и без публикации:

```text
node --test worker/tests/amo-tags.test.mjs
wrangler deploy --dry-run --config worker/wrangler.jsonc
```

Секрет `AMO_LONG_LIVED_TOKEN` хранится только в Cloudflare и в Git не
добавляется. Публикация Worker выполняется отдельно после одобрения изменений.
